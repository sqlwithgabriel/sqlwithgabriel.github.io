Hi, I'm **Gabriel da Silva**, a Database Engineer from São Paulo, Brazil, focused on SQL Server and PostgreSQL performance, reliability and cloud cost.

I've spent the last 4+ years running mission-critical database environments, including for international clients. Today I'm a Database Engineer at **Velozient**, working remotely for a global software company on a highly transactional, multi-terabyte platform on AWS and Azure that ingests data from thousands of sites worldwide.

## What I work on

- **Performance troubleshooting and query tuning:** wait statistics, execution plans, indexing, I/O and storage bottlenecks
- **High availability and disaster recovery:** Always On Availability Groups, backup and restore strategy
- **Database DevOps:** Git-based CI/CD for database changes and infrastructure as code with AWS CloudFormation
- **Cloud:** cost reduction, migrations and upgrades across AWS and Azure
- **Operations:** automation of recurring tasks, capacity planning and production incident response
